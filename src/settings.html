Интерфейс

Ширина панели 440 px
Высота панели 33 %
Доля от высоты рабочего стола. Панель остаётся у правого края.
Стеклянный фон
Размытый задник окна: видно то, что находится позади виджета. Требует включённых эффектов прозрачности в Windows.
Размытие фона
Размывает то, что за окном (системный Acrylic). Он добавляет свою тёмную подложку, поэтому выключенное размытие выглядит прозрачнее.
Прозрачность фона 45 %
Чем выше, тем сильнее виден размытый задник и тем стекляннее панель. На 0 % панель полностью залита цветом.
Прозрачность карточек 30 %
Поле ввода и карточки сообщений в переписке. Они всегда плотнее фона, чтобы текст оставался читаемым; код и поля ввода не прозрачнеют.
Положение окна
Виджет запоминает положение и размер, которые ты задал мышью. Эта кнопка возвращает его к правому краю экрана.
Уведомление Windows
Тост в углу экрана, когда ответ готов. Виден даже там, где всплытие окна заметить нельзя — например, в полноэкранной игре. Клик по нему открывает виджет.
Звук уведомления
Звуковой сигнал вместе с тостом.
Всплывать при ответе агента
Когда агент закончил отвечать, а окно спрятано — оно выедет из-за края само.
Анимация появления
Окно выезжает из-за правого края и уезжает обратно.
Горячая клавиша
Открывает и скрывает виджет из любого места. Нажми на сочетание, затем нажми новое. Esc — отмена, Backspace — вернуть по умолчанию.
Клавиша «писать сразу»
Открывает виджет и сразу ставит курсор в поле ввода — можно печатать без лишнего клика. Esc — отмена, Backspace — вернуть по умолчанию.

Подключение

Папка лаунчера
Где лежат state/harness.json с адресом харнесса и скрипты Start-Harness.ps1/Stop-Harness.ps1. Нужна только для этих возможностей: подключение работает и без неё.
Адрес харнесса
Если пусто — адрес берётся из состояния лаунчера. Меняя адрес, виджет перезагрузит страницу.

Размер текста 136 %
Основной размер: переписка, поле ввода, кнопки. Ниже — отдельные поправки для меню и диалога выбора модели.
Шрифт в меню 100 %
Меню сессий, которое открывается по логотипу слева вверху.
Шрифт в диалоге выбора модели 100 %
Всплывающее меню модели и режима рассуждений.
